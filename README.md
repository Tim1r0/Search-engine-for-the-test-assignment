
# Поисковик по текстам документов (Search Engine)

Сервис для полнотекстового поиска по документам. Принимает произвольный текстовый запрос, ищет совпадения в Elasticsearch и возвращает первые 20 документов из базы данных PostgreSQL, отсортированных по дате создания. Поддерживает загрузку данных из CSV и удаление документов.

## 🛠 Технологический стек

- **Python 3.14**
- **FastAPI** — веб-фреймворк для создания API.
- **SQLAlchemy (Async)** + **PostgreSQL** — хранение основных данных документов.
- **Elasticsearch 9.5.5** — поисковый индекс.
- **Alembic** — миграции базы данных.
- **Docker & Docker Compose** — контейнеризация и запуск окружения.
- **Poetry** — управление зависимостями.
- **Pytest** — функциональные тесты.

## 🚀 Функционал

- **Поиск документов**: принимает текстовый запрос, ищет по тексту в Elasticsearch, возвращает до 20 документов с полями из БД, отсортированных по `created_date`.
- **Загрузка CSV**: асинхронная обработка загруженного CSV-файла с валидацией данных и индексацией в Elasticsearch.
- **Удаление документов**: удаление записи из PostgreSQL и Elasticsearch по ID.
- **Асинхронность**: все операции ввода-вывода (БД, Elasticsearch) выполняются асинхронно.
- **Swagger UI**: автоматическая документация API доступна по адресу `/docs`.

## 📦 Запуск через Docker

Самый простой способ запустить проект — использовать Docker Compose. Всё необходимое окружение (PostgreSQL, Elasticsearch, веб-приложение) поднимется автоматически.

### Предварительные требования
- Установленный [Docker](https://www.docker.com/) и [Docker Compose](https://docs.docker.com/compose/).

### Инструкция по запуску

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Tim1r0/Search-engine-for-the-test-assignment.git
   cd Search-engine-for-the-test-assignment
   ```

2. Запустите сборку и старт контейнеров:
   ```bash
   docker-compose up --build -d
   ```
   *Примечание: при запуске контейнера `web` автоматически применяются миграции Alembic (`alembic upgrade head`), после чего запускается FastAPI.*

3. Проверьте статус контейнеров:
   ```bash
   docker-compose ps
   ```
   Все сервисы (`pg`, `es`, `web`) должны быть в статусе `Up` или `Healthy`.

4. Сервис будет доступен по адресу:
   - API: `http://localhost:8080`
   - Swagger UI (документация): `http://localhost:8080/docs`

5. Для остановки контейнеров:
   ```bash
   docker-compose down
   ```

## 📖 Документация API (OpenAPI)

Полная спецификация API доступна в файле `docs.json` в корне проекта. Также интерактивная документация автоматически генерируется FastAPI и доступна по адресу `http://localhost:8080/docs` после запуска сервиса.

### Основные эндпоинты

#### 1. Поиск документов
```http
GET /api_v1/search?query={текстовый_запрос}
```
**Пример:**
```bash
curl "http://localhost:8080/api_v1/search?query=привет"
```
**Ответ:** Массив объектов документов (до 20 штук), отсортированных по дате создания.

#### 2. Загрузка CSV
```http
POST /api_v1/upload_csv
Content-Type: multipart/form-data
```
**Пример:**
```bash
curl -X POST "http://localhost:8080/api_v1/upload_csv" \
     -F "file=@data.csv"
```
*Формат CSV должен содержать колонки: `text`, `created_date` (формат `YYYY-MM-DD HH:MM:SS`), `rubrics` (список в виде строки, например `['1', '2']`).*
Обработка файла происходит в фоновом режиме (BackgroundTasks).

#### 3. Удаление документа
```http
DELETE /api_v1/documents/{document_id}
```
**Пример:**
```bash
curl -X DELETE "http://localhost:8080/api_v1/documents/1"
```

## 🧪 Тестирование

Для запуска функциональных тестов локально (при наличии запущенных контейнеров `pg` и `es`) выполните:

```bash
poetry run pytest
```

Тесты проверяют:
- Корректность поиска документов.
- Обработку пустых результатов поиска.
- Успешную загрузку CSV.
- Обработку ошибок при удалении несуществующего документа.


## ⚙️ Переменные окружения

При запуске через `docker-compose` переменные задаются автоматически. Для локального запуска без Docker создайте файл `.env` в корне проекта:

```env
E_SEARCH__DB__URL=postgresql+asyncpg://user:user@localhost:5432/esearch
E_SEARCH__ES__URL=http://localhost:9200/
E_SEARCH__RUN__HOST=0.0.0.0
E_SEARCH__RUN__PORT=8080
```
